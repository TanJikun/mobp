# 功能

- 让office常驻后台以快速启动

- 每次打开office都让其最大化

# 兼容性

只在Windows10+测试过，只有Windows

# 为什么有

我们学校电脑打开PPT要一分钟，找到原仓库之后窗口很小一个缩在左上角导致老师用了一节课黑板。一气之下用了AI写出来这个。
